# Starter Pack — Анализ рынка Roblox и как делать игры

> **Назначение:** база знаний для выбора идеи, оценки потенциала и проектирования retention **до** написания кода.  
> **Обновлено:** 2026-07-09  
> **Источники:** RBXCodes, GGAID, BloxQuiz, Roblox DevForum (RFY 2026), Dubit, StudioKrew, кейсы GaG / Brainrot / Animal Hospital.

Эта папка **не привязана** к Deep Digger / DEEP SIGNAL. Это универсальный фреймворк для любого Roblox-проекта.

**Idea Machine** (конвейер идей, 6 проектов/год, калибровка): **[machine/README.md](./machine/README.md)**

**Brand & Social Starter Pack** (группы, Discord, YouTube, тон, тексты, визуал): **[../../../roblox-starter/docs/brand-and-social/README.md](../../../roblox-starter/docs/brand-and-social/README.md)** (канон) · копия в `assets/marketing/starter_pack/`

## Как пользоваться

1. Прочитай **[01-meta-pattern.md](./01-meta-pattern.md)** — один паттерн, который повторяется в топ-50.
2. Пройди идею через **[09-idea-checklist.md](./09-idea-checklist.md)** — scorecard до старта разработки.
3. Выбери **engines** в **[02-seven-engines.md](./02-seven-engines.md)** — минимум 2–3 слоя.
4. Сверься с **[03-top50-rank-analysis.md](./03-top50-rank-analysis.md)** — не клонируешь ли переполненную полку.
5. Спроектируй retention по **[04-retention-playbook.md](./04-retention-playbook.md)**.
6. Учти алгоритм **[05-roblox-algorithm-2026.md](./05-roblox-algorithm-2026.md)**.
7. Проверь hook и визуал **[06-visual-and-hook.md](./06-visual-and-hook.md)**.
8. Следуй процессу **[07-how-to-design-a-hit.md](./07-how-to-design-a-hit.md)**.
9. Избегай **[08-anti-patterns.md](./08-anti-patterns.md)**.

## Главный вывод одной строкой

> Успешная Roblox-игра = **одно понятное действие** + **видимый прогресс каждые секунды** + **бесконечная охота** + **другие игроки в цикле** + **причина вернуться завтра**.

Grow a Garden — **один из 14 IDLE-игр** в топ-50, не весь рынок.
