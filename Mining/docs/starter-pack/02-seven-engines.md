# Семь Engines (E1–E7)

> **Engine** = самодостаточный retention-двигатель. Хиты комбинируют **2–4 engine**. Один engine = узкий потолок.

---

## Сводная таблица

| ID | Engine | Суть | RETURN-механизм | Игр в топ-50 |
|----|--------|------|-----------------|--------------|
| **E1** | IDLE | Пассивный доход, offline progress | «Накопилось, зайду» | ~14 |
| **E2** | NUMBER | Число растёт + rebirth multiplier | «1.5M → хочу 2M» | ~12 |
| **E3** | COLLECTION | Редкость, гача, журнал % | «Нет mythic» | ~22 |
| **E4** | SOCIAL | RP, trade, vote, hangout | «Друзья онлайн» | ~18 |
| **E5** | SESSION | Раунды, co-op, stakes в сессии | «Ещё одну смену» | ~16 |
| **E6** | SKILL | PvP, mastery, rank | «Стану лучше» | ~14 |
| **E7** | CULTURE | Мем, тренд, viral | «Все играют» | ~5 (overlay) |

---

## E1 — IDLE (Passive Accumulator)

**Паттерн:** купил → генерирует $/sec → апгрейд → rebirth

| Игра | Пассив |
|------|--------|
| Grow a Garden | Растения растут offline |
| Steal a Brainrot | Brainrots на базе |
| Pet Sim 99 | Pets auto-farm |
| Sell Lemons | Automators, burst-and-sleep |
| Mukbang Game | Eat → grow |

**Solo dev:** низкая сложность, **высокая конкуренция** в 2026.

**Дифференциатор нужен:** не «ещё один сад», а уникальный noun (лимоны, brainrot, клавиатура).

---

## E2 — NUMBER (Incremental)

**Паттерн:** stat += action → spend → multiplier → rebirth → stat растёт быстрее

| Игра | Stat |
|------|------|
| +1 Speed Keyboard Escape | Speed |
| Drain the Lake | Water drained |
| Pet Sim 99 | Coins + rebirth |
| Sol's RNG | Aura tier |

**Ключ:** число **всегда на экране**, растёт каждую секунду.

**Clip bait:** «SPEED 50,000,000» на thumbnail.

---

## E3 — COLLECTION (Rarity Chase)

**Паттерн:** hatch/catch/roll → tier (common→mythic) → flex/trade

| Игра | Коллекция |
|------|-----------|
| Adopt Me | Pets |
| Fisch / Fish It | Fish |
| Blox Fruits | Fruits |
| GaG | Mutations |
| Evomon | Creatures |

**Обязательно:** reveal moment (VFX + sound + rarity banner).

---

## E4 — SOCIAL

**Паттерн:** ценность создаётся **между игроками**

| Подтип | Игры |
|--------|------|
| Sandbox RP | Brookhaven, Berry Avenue |
| Trading economy | Adopt Me, Pet Sim |
| Steal drama | Brainrot |
| Fashion vote | Dress To Impress |

**2026:** Spatial Voice удлиняет сессии в RP (45–60 мин Brookhaven).

---

## E5 — SESSION (Round / Co-op Stakes)

**Паттерн:** сессия с началом и концом, stakes внутри

| Игра | Stakes |
|------|--------|
| 99 Nights | База пропадёт если выйти |
| Animal Hospital | Shift #, sanity |
| MM2 | Раунд 5–10 мин |
| Evade | Поймают = down |
| Clean The Library | Speedrun time |

**Тренд 2026:** растёт быстрее чем IDLE-клоны.

**Solo dev:** co-op проще чем MMO, но нужен netcode + баланс.

---

## E6 — SKILL

**Паттерн:** mastery, PvP, rank

| Игра | Skill expression |
|------|------------------|
| RIVALS | FPS aim |
| Blox Fruits | Combat combos |
| Jujutsu Shenanigans | Fighting |

**Retention:** бесконечный skill ceiling, но **уже насыщенные полки**.

## E7 — CULTURE (Overlay)

**Не standalone.** Усиливает любой engine:

| Пример | Культурный момент |
|--------|-------------------|
| Steal a Brainrot | Italian brainrot memes |
| GaG peak | Cozy + TikTok |
| Catch a Brainrot | Pokemon × memes |

**Риск:** окно закрывается. Нужна скорость ship.

## Сильные комбо для solo (40 дней)

| Комбо | Пример на рынке | Почему |
|-------|-----------------|--------|
| **E5 + E3** | Animal Hospital | Co-op + progression |
| **E2 + E7** | Keyboard Escape | Viral numbers + theme |
| **E1 + E3 + secrets** | Sell Lemons | Prestige + hidden zones |
| **E1 + E3 + E4** | Brainrot | Пассив + steal + trade |
| **E5 + E4** | 99 Nights | Session + friends |

## Слабые комбо

| Комбо | Проблема |
|-------|----------|
| E1 alone | «Ещё один сад» |
| Story only | D30 = 0 |
| E6 alone без E3 | Мало long-tail retention |
| E4 alone без voice/friends | Нужна критическая масса |

---

## Как выбрать engines для своей игры

1. Выбери **primary** (главный RETURN): E1, E2, E5 или E4.
2. Добавь **secondary** для D30: обычно E3 или E2.
3. Добавь **social layer** если возможно: E4 subset (trade, co-op, steal).
4. Проверь: есть ли **RETURN timer** (слой 7 мета-паттерна)?
