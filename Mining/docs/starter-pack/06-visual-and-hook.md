# Visual, Hook & Thumbnail

> Первое впечатление решает **bounce rate** → RFY в 2026.

---

## 10-секундный HOOK

Игрок должен понять **без текста**:

1. **Что я делаю?** (verb)
2. **Что получу?** (награда / число / редкость)
3. **Почему интересно?** (опасность / соревнование / милота)

### Примеры сильных hook

| Игра | Hook |
|------|------|
| Steal a Brainrot | Воруй мем-персонажей, база генерит $ |
| Keyboard Escape | Каждый шаг +1 speed |
| Animal Hospital | Проверяй пациентов — кто-то фейк |
| 99 Nights | Переживи ночь в лесу |
| Sell Lemons | $1 → лимонная империя |

### Слабые hook

- «Epic Adventure Awaits»
- «Best Mining Simulator 2026»
- Скриншот меню без action

## Thumbnail (512×512 + 1920×1080)

### Правила Roblox 2026

| Правило | Почему |
|---------|--------|
| **Нет мелкого текста** на 512×512 | Нечитаемо в сетке |
| **Один фокус** | Персонаж / объект / число |
| **Высокий контраст** | Тёмный фон + яркий accent |
| **Обещание = правда** | Иначе first play bounce |
| 3 thumbnail в ротации | A/B разные hooks |

### Рабочие overlay (на 1920×1080)

| Тип | Пример текста |
|-----|---------------|
| Mystery | `SOMETHING IS WRONG HERE` |
| Numbers | `+1 SPEED EVERY STEP` |
| Depth/status | `SHIFT 47 — CAN YOU BEAT IT?` |
| Collection | `MYTHIC PULL` (скриншот момента) |

## Визуальные стили в топ-50

| Стиль | % топ-50 | CCU потолок | Когда выбирать |
|-------|----------|-------------|----------------|
| Low-poly cozy | ~30% | Высокий | E1 sim, детская аудитория |
| Brainrot neon | ~10% | Viral peak | E7 cultural moment |
| Candy saturated | ~8% | Fast rise | E2 incremental |
| Horror atmospheric | ~20% | Rising 2026 | E5 session |
| Anime VFX | ~18% | Stable | E6 RPG/fighting |
| Realistic RP | ~14% | Evergreen | E4 social |

### Технические требования

- **Mobile first** — budget Android
- **<10k tris** на hero asset
- **VFX на reveal** — hatch, mutation, legendary, rebirth
- **Silhouette** узнаваем за 0.5 сек
- **Sound** — ASMR click, rarity sting, storm rumble

## Reveal Moment (обязателен для E3)

Каждая игра с коллекцией имеет **один** отполированный момент:

| Элемент | GaG | Brainrot | Pet Sim |
|---------|-----|----------|---------|
| Screen flash | ✅ | ✅ | ✅ |
| Camera shake | лёгкий | средний | средний |
| Sound sting | ✅ | ✅ | ✅ |
| Rarity banner | ✅ | ✅ | ✅ |
| Share prompt | implicit | TikTok | Discord |

**Без reveal moment** — слабый TikTok / organic.

## Loading screen & first 60 sec

| Время | Что показывать |
|-------|----------------|
| 0–5с | Logo + tagline (1 фраза) |
| 5–15с | Уже в gameplay, не меню |
| 15–60с | Первый reward, первый «вау» или tension |

**Правило Dress To Impress / GaG:** show don't tell. Минимум text tutorial.

### Rotating tips (max 5)

Пример формата:
- `The shop restocks every 5 minutes.`
- `Rare items only appear during events.`
- `Invite a friend for a bonus.`
