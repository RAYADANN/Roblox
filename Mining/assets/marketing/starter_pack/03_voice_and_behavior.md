# 03 — Voice & Behavior Model

> **Главный файл.** Один и тот же бренд — разный голос на каждой площадке.  
> Это не «разные личности», а **адаптация формата**, суть одна.

---

## Общие правила (везде)

### Делай

- Пиши от первого лица множественного («мы») или от студии — solo dev, но «Zeon Studio» как бренд
- Благодари за поддержку, особенно в launch/update постах
- Давай конкретику: цифры, фичи, ссылки
- Отвечай на баги и идеи — «читаем всё»
- CTA в конце: играть / группа / избранное / Discord

### Не делай

- Fake «FREE ROBUX» / scam tone
- ALL CAPS весь пост (только заголовки / 1–2 слова)
- Обещания на thumbnail, которых нет в игре
- Агрессивный clickbait («YOU WON'T BELIEVE»)
- Копипаста одного текста во все каналы без адаптации
- Lore-слова (Wanderer, Transmission) в Roblox Group — там они неуместны

## Матрица поведения по площадкам

| | Roblox Group | Discord | YouTube | Game Page |
|---|:---:|:---:|:---:|:---:|
| **Тон** | Дружелюбный, прямой | Атмосферный + community | Профессиональный dev | SEO, feature-list |

| **CTA** | Игра + группа + fav | Portals + roles | Subscribe + play | Group bonus |

## Roblox Group — как писать

**Роль:** официальный канал студии для игроков Roblox.  
**Аудитория:** дети/подростки, mobile, быстро скроллят.

### Формула поста

```
[Эмодзи] ЗАГОЛОВОК (1 строка — что случилось)

2–3 предложения контекста — что это значит для игрока.

✨ Список фич / что нового (3–6 пунктов)

🎁 Бонус / промокод (если есть)

👉 Ссылка на игру
👍 Like & Favorite

💬 Призыв написать фидбек
— Zeon Studio
```

### Shout (стена) — формула

```
🆕 [Событие в 3–5 словах]
⛏️ [Hook одной строкой]
🎁 [Бонус если есть]
👉 [ссылка]
```

### Примеры заголовков

- `🆕 DEEP DIGGER — уже в Roblox!`
- `🔧 UPDATE 1.1 — новый слой Void`
- `🎁 PROMO CODE — [CODE]`
- `🏆 Event — Top Depth Challenge`

### Частота

| Тип | Как часто |
|-----|-----------|
| Major update | 1 пост + shout |
| Minor patch | shout или комментарий |
| Promo code | shout + Discord #drops |
| «Спасибо за X visits» | 1 раз на milestone |

## Discord (Zeon Network) — как писать

**Роль:** дом для community, не рекламная лента.  
**Аудитория:** engaged игроки, потенциальные моды, фанаты.

### Формула #signals (announcement)

```
📡 **TRANSMISSION #XXX — [TITLE]**

[1–2 предложения по делу]

• Bullet что изменилось
• Bullet что изменилось

▶ Portal: [game link]
✦ Stay tuned, Wanderer.
```

### Формула #drops

```
🎁 **SUPPLY DROP — [CODE NAME]**

`CODE_HERE`

Rewards: [что даёт]
Valid until: [дата или «limited»]

Grab @Codes role in #🌌·arrival for future drops.
```

### Формула #lounge / community

- Можно расслабленнее, но без токсичности
- Помогай в #help — коротко, по пунктам
- Баги → направляй в #glitches с шаблоном
- Идеи → #beacons

### Чего избегать

- Пинг @everyone без major news
- Спам апдейтами (объедини в один transmission)
- Официальный тон в #lounge (там можно проще)

## YouTube — как писать

**Роль:** devlog / trailer / credibility для новых игроков и Roblox algo.

### Формула описания видео

```
⛏️ DEEP DIGGER — [контекст видео]

🎮 Play: [link]
👥 Group reward: [link]
💬 Discord: [invite]

⏱️ TIMESTAMPS
0:00 Intro
...

🔔 Subscribe for devlogs & updates from Zeon Studio!

#Roblox #DeepDigger #ZeonStudio #RobloxDev #MiningSimulator
```

### Тон на видео (если озвучка)

- Спокойный, уверенный, не «YouTuber hype»
- Показывай реальный gameplay
- Честно про solo dev и roadmap

---

## Game Page (Creator Hub) — как писать

**Роль:** конверсия в Play + SEO.

- **English only** на странице игры
- Feature bullets с emoji
- Social reward упомянуть
- Tags: Mining, Simulator, Pets, Rebirth, Idle, Upgrade
- Без lore, без Discord slang

## Ответы на типичные ситуации

| Ситуация | Roblox Group | Discord |
|----------|--------------|---------|
| Баг | «Спасибо! Передали / фиксим в следующем патче» | Шаблон в #glitches, react ✅ когда взято |
| «Когда update?» | «В разработке, следи за группой» | #signals когда готово |
| «Дайте робуксы» | Игнор / «нет free robux» | Удалить + warn |
| Идея | «Классная идея, записали!» | «Постни в #beacons» |
| Хейт | Не кормить | Mod action по charter |

## Модель «один голос — три регистра»

```
STUDIO CORE (внутренний):
  «Solo indie. Multiverse. Honest updates. Free rewards for support.»

↓ Roblox Group     = Core + простой язык + emoji + CTA
↓ Discord          = Core + lore wrapper (Wanderer, signals)
↓ YouTube          = Core + dev transparency + timestamps
↓ Game Page        = Core + SEO features + EN
```

Перед публикацией спроси себя: **«Это звучит как Zeon Studio из Core?»**
