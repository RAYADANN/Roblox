## Как занести в Figma

1. Открой `figma_v3_all_windows.html` в Chrome.  
2. В Figma: **New file** → создай page `Breed Raid v3`.  
3. Вариант A: перетащи PNG-артборд (`breed_raid_figma_artboard_v3_all_windows.png`).  
4. Вариант B: скринь каждый `.frame` отдельно → **Place image** / `Ctrl+Shift+K` → обведи Frame.  
5. Плагин (опционально): *html.to.design* — импорт HTML в editable layers (качество ~70%).
