# R02 — Apex Legends HUD (squad + abilities)

**Study focus:** multi-player status + ability cooldowns without drowning the shooter view.

## Player task
Track self resources, squad, and tactical cooldowns while aiming.

## Hierarchy
1. Center aim  
2. Ammo / health / shields  
3. Ability charges (distinct shapes, not color-only)  
4. Squad portraits / pings — secondary edge  

## Why it feels pro
- Ability state readable mid-fight (shape + fill).  
- Squad info peripheral; doesn’t steal crosshair.  
- Ping system = spatial UI + audio vocabulary.

## Steal
- Cooldown = sweep/fill + icon state, not only timer text.  
- Teammate status as compact chips, not full panels.  
- Distinct shapes per ability.

## Do not copy
Legend kits, font lockup, Battle Pass chrome.
