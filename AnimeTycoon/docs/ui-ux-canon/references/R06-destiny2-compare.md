# R06 — Destiny 2 item compare

**Study focus:** decision speed via deltas, not walls of absolute numbers.

## Player task
Decide equip/replace in seconds.

## Hierarchy
1. Item identity (name/rarity)  
2. **Delta arrows** vs currently equipped  
3. Perks / notes  
4. Flavor  

## Why it feels pro
- Comparison is first-class layout, not a spreadsheet dump.  
- Rarity readable but not the only signal.  
- Power/stat change scannable left-to-right.

## Steal
- Always show ↑↓ or +/- vs baseline.  
- Align stat columns.  
- Locked/owned/equipped badges consistent.

## Do not copy
Bungie iconography; light-level fantasy into unrelated genre without mapping.
