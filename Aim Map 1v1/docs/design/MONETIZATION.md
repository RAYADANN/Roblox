# Monetization — Aim Map 1v1

## Принцип

Игроки приходят за **aim / duel**. Деньги — только **косметика и статус**. Никакого P2W.

## MVP shop

| Продукт | Заметка |
|---|---|
| USP (default) | Бесплатно всегда |
| 5–15 skins USP | Дешёвые + mid + 1 flex |
| Bundles (опц.) | 2–3 скина пачкой |
| Gamepass QoL | Только не-сила (name color / lobby flair). Не skip-queue / не damage |

## Kill-flex (ключевая петля)

```
Убил врага → носишь его скин USP до СВОЕЙ смерти
Shop = единственный способ владеть скином навсегда
```

| Вариант | Статус |
|---|---|
| До своей смерти | ✅ канон |
| Навсегда с килла | ❌ ломает кассу |
| Только killcam | слабо; можно как доп. FX |

### Усилители покупки

- Post-win / death: CTA «Unlock this skin»
- Лобби: видны скины ожидающих
- Win screen: крупный USP winner
- Rare: лёгкий muzzle/tracer (не aim advantage)

## После product-market fit

1. Больше скинов / эффектов  
2. 2-я карта  
3. 2-е оружие (новый каталог скинов)  
4. Season cosmetics (не P2W elo boost)

## Экономическая петля

```
Дуэль → увидел чужой скин на kill-flex
     → захотел владеть
     → купил в shop
     → сам реклама для следующего
```

Бесплатный grind-путь (простые скины / streak) + Robux flex (лучшие).
