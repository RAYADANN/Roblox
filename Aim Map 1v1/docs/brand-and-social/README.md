# Brand & Social — не часть архитектуры шаблона

> **Важно для новых игр:** эта папка — **архив промо** конкретной игры (Deep Digger), не канон стека/архитектуры.
> При копировании `roblox-starter` → новый проект: **замени или удали** эти файлы под свою игру.
