# R12 — Fair shop / store trust pattern

**Study focus:** monetization UI that preserves long-term trust (professional product ethics).

## Player task
Understand what they buy and whether they already own it.

## Hierarchy
1. Price + currency type  
2. Contents / benefits list  
3. Owned / equipped state  
4. Marketing art — support, not liar  

## Why it feels pro
- No hidden math between soft currencies.  
- Bundle contents explicit.  
- Regional pricing clarity where applicable.  
- Confirm step for spend.  
- Failures explained (not enough funds → CTA earn/buy).

## Steal
- Owned check before purchase CTA.  
- Soft and Robux buttons different variants.  
- Receipt-like success toast.  

## Do not copy
Fake scarcity timers, disguised odds, pressure full-screen every death, “almost free” lies.
