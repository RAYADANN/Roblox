# R09 — Hades reward / choice screens

**Study focus:** high-stakes choice UI that stays readable under excitement.

## Player task
Pick a boon/reward quickly with clear tradeoffs.

## Hierarchy
1. Offer identity (god/theme)  
2. Effect text — scannable verbs  
3. Rarity/quality cue  
4. Flavor / lore — last  

## Why it feels pro
- Choices are parallel cards with equal scan path.  
- Key numbers/verbs bolded in text craft.  
- Celebration juice doesn’t hide the decision.  
- Skip/advance respects pace.

## Steal
- Equal card anatomy for mutually exclusive choices.  
- Put mechanical effect before lore.  
- Short juice, then stable readable state.

## Do not copy
Supergiant art directly; Greek theme into unrelated IP.
