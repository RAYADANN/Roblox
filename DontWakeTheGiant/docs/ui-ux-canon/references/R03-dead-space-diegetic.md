# R03 — Dead Space (diegetic UI limits)

**Study focus:** fiction-integrated health/inventory; when diegetic helps and when it hurts a11y.

## Player task
Manage fear and resources inside world fiction.

## Hierarchy
1. Health spine on suit (diegetic + spatial)  
2. Aim / stasis  
3. Inventory as holographic in-world panel  

## Why it feels pro
- UI reinforces fantasy instead of fighting it.  
- Still highly readable in corridor lighting (mostly).

## Steal
- Diegetic only if you can keep contrast and scale options.  
- Tie UI materials to character tech.

## Do not copy
- Blindly diegetic text that fails colorblind/TV tests.  
- Horror chrome on a bright arcade sim (genre clash).
