# R05 — Persona 5 menus (focus & stylized chrome)

**Study focus:** extreme style that still has ruthless focus, hierarchy, and motion grammar.

## Player task
Navigate menus with confidence; style is the brand.

## Hierarchy
1. Selected row / focused card — unmistakable  
2. Section title  
3. Secondary metadata  
4. Decorative shapes — ambient, never compete with focus  

## Why it feels pro
- Style is systematic (angles, red/black, motion verbs), not random stickers.  
- Focus state always obvious.  
- Transitions are a language (slash, swipe), reused.

## Steal
- Pick 2–3 motion verbs and reuse.  
- Let decoration lose to selection contrast.  
- Bold brand OK if tokens are consistent.

## Do not copy
Literal Persona motifs/IP; unreadable fancy fonts for body text in Roblox HUD.
