# R10 — Resident Evil 4 attaché (spatial inventory)

**Study focus:** inventory as a spatial puzzle — when grid packing is the game.

## Player task
Tetris-manage limited space under pressure.

## Hierarchy
1. Grid occupancy / shape of items  
2. Selected item ghost  
3. Stats/description side panel  
4. Atmosphere frame  

## Why it feels pro
- UI *is* the mechanic, so clarity of cell size and rotation is sacred.  
- Threat of space creates tension without extra chrome.  
- Consistent cell metric.

## Steal (only if packing is intentional)
- Fixed cell size, clear invalid placement.  
- Rotation affordance obvious.  

## Do not copy into pet sim
- Don’t force tetris bags if your loop is “equip best pet”. Use sortable lists instead (`01` surfaces).
