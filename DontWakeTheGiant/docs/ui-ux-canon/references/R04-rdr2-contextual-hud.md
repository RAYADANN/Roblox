# R04 — Red Dead Redemption 2 (contextual HUD)

**Study focus:** progressive disclosure — UI appears when needed, fades when not.

## Player task
Exist in world; HUD not a constant dashboard.

## Hierarchy
1. World / cinematic framing first  
2. Weapon/cores appear on change or need  
3. Interaction prompts contextual  
4. DeadEye / meters when relevant  

## Why it feels pro
- Immersion without abandoning clarity.  
- Veteran-friendly low chrome; still teaches via appearance.

## Steal
- Fade non-critical HUD after idle.  
- Flash objective, then quiet.  
- Prompt only near interactable.

## Do not copy
Full western ornament into mobile sim dock; slow cinematic pacing if your session is 5 minutes.
