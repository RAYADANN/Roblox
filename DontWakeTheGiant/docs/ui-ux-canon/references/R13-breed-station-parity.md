# R13 — Breed / station parity (sim fuse pattern)

**Study focus:** information design for roll stations + incubate/fuse — composite from BaBaS-likes and breed UIs. Not one IP.

## Player task
Preview odds → pay → place creature; optionally fuse two parents and wait.

## Hierarchy (station)
1. **1 in X** (or equivalent flex)  
2. Action verb (Roll / Buy) + price in ObjectText  
3. Name / meta ($/s, qty)

## Hierarchy (fuse)
1. Two parents selected (clear selected state)  
2. Expected outcome odds  
3. Start (primary) · optional paid speed with **cost on CTA** · Close

## Why good implementations feel expensive
- Screen panel and pad billboard show the **same** odds and price.  
- Custom prompt chrome matches HUD surfaces.  
- Empty roll state is one clear CTA, not a hollow frame.  
- Outdoor text sits on cream/dark cards — never bare on grass.

## Why bad ones feel cheap
- Default ProximityPrompt + neon pads.  
- Modal shows odds; world shows only “E”.  
- Soft-speed / skip without price on the button.  
- White text on mid-tone jade buttons.

## Steal
- Odds-as-hero typography (canon 04 + 20).  
- Card shell + content frame (layout never siblings with accent chrome).  
- Hold progress for steal/deposit.  
- Measured AA on CTA labels (`textDark` on mid fills).

## Do not copy
Specific BaBaS art, trademarked pets, predatory shop layouts.
