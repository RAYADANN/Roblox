# 00 — Priority Ladder (не утонуть в каноне)

Канон большой **намеренно**. Это не значит «сделай всё из 18 файлов перед шипом».

Используй **лестницу**. Ниже ступень не открывай, пока верхняя не зелёная для **текущего scope**.

---

## Лестница фаз

| Фаза | Вопрос | Документы | Ship без стыда? |
|------|--------|-----------|-----------------|
| **L0 Loop** | Игрок понимает verb и хочет ещё раз? | GDD / MVP | Да — серый UI ок |
| **L1 Read** | Читается на худшем фоне за ≤0.5s? | 02, 03, 04, 08 | Да — простой chrome |
| **L2 Respond** | Каждый input ≤100ms отвечает? | 07, 11, 13 | Да — must |
| **L3 System** | Tokens + 8pt + states + empty/error? | 03–07, 18 | Да — «проф. база» |
| **L4 World** | Prompts/billboards = тот же язык? | 10, 15, 22 | Да для Roblox |
| **L5 Genre** | HUD/меню совпадают с жанром? | 19, 20 | Да |
| **L6 Delight** | Juice на ключевых моментах? | 11 + project delight spec | Опционально |
| **L7 Ornament** | Баннеры, texture, marketing chrome? | 06 (дозировка) | **После** L3–L5 |

**Правило:** L7 без L1–L3 = «красивая оболочка мёртвого loop» — запрещено называть профессиональным.

## Сколько читать агенту

| Задача | Минимум |
|--------|---------|
| Починить кнопку | QUICK + 07 + professional-ui.mdc |
| Новая палитра | 00 → 03 → 20 (если sim) → theme |
| Новый экран | `templates/screen-brief.md` → жанр 19/20 → 07/09 → 18 |
| «Сделай топовый UI» | L0 честно → L1–L4 → references → L6 |
| Полный канон | Только при создании design system с нуля |

---

## Definition of «достаточно для этой недели»

Выпиши 3 bullet:

1. Какой **один** экран/HUD ломает доверие сильнее всего?  
2. Какая ступень лестницы на нём красная?  
3. Что **не** трогаем (явно).

Без пункта 3 polish расползается.
