# BACKLOG — идеи вне текущего scope

Записывай сюда всё, что **не** входит в текущую задачу / MVP.
Cursor не реализует без явного запроса.

Формат:

```markdown
## [Название]
- **Зачем:** одна строка
- **Приоритет:** после MVP / 1.1 / 1.2
- **Зависимости:** что нужно до этого
```
