# Playtest Checklist

Перед каждым soft launch / апдейтом. Проверяет **человек** (Cursor не играет).

## Устройства

- [ ] Phone (iPhone SE или аналог, landscape)
- [ ] Tablet (iPad или 768×1024)
- [ ] Desktop (1920×1080)

## HUD / UI

- [ ] Текст читаем без зума
- [ ] Кнопки нажимаются (touch target ≥ 44px на phone)
- [ ] Модалки не обрезаются, close работает
- [ ] Нет overlap с Roblox topbar
- [ ] Rotate device → UI не ломается

## Геймплей

- [ ] Петля MVP проходима за 15 мин (см. MVP_SLICE.md)
- [ ] Прогресс сохраняется после rejoin
- [ ] Нет дюпа монет / предметов
- [ ] Ошибки сети → toast, не crash

## Перф

- [ ] FPS ≥ 30 на phone в типичном геймплее
- [ ] Нет заметных фризов при sell / upgrade / FX

## Звук / настройки

- [ ] UI click слышен
- [ ] SFX volume работает (если Settings есть)
- [ ] Reduce motion отключает shake/rain (если есть)

## Монетизация (если в билде)

- [ ] Покупка проходит в Studio test mode
- [ ] Начисление один раз (не дюп при rejoin)

## Мультиплеер (обязательно для косметики / мира)

Studio → Test → **Start** с **2 Players** (или второй аккаунт в Team Test).

- [ ] Второй игрок **видит** 3D-косметику первого (петы, aura, trail — если есть в билде)
- [ ] Второй игрок **не видит** чужой HUD / модалки (только свой UI)
- [ ] Экипировка / смена косметики у первого **обновляется** у второго без rejoin
- [ ] Rejoin первого игрока — косметика снова видна другим
- [ ] Состояние мира (сломанные блоки, двери — если есть) совпадает у обоих
