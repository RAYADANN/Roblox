# R07 — Nintendo first-party menus (clarity)

**Study focus:** affordances so clear that kids and grandparents both succeed.

## Player task
Select mode/option without documentation.

## Hierarchy
1. Primary action / mode cards — large  
2. Supporting description — short  
3. System status (players, online) — edge  
4. Decoration — minimal  

## Why it feels pro
- Big hit targets, obvious selected state.  
- Copy is plain.  
- Motion is friendly but short.  
- Consistency across titles teaches transfer.

## Steal
- Enlarge primary choices; shrink settings density.  
- One sentence helper under title.  
- Never rely on icon alone for rare actions.

## Do not copy
Specific Mario/Zelda motifs; underestimating your players’ need for depth in sim menus (balance clarity with power).
