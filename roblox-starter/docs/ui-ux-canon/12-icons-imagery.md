# 12 — Icons & Imagery

## Иконки

### Правила

1. **Один стиль** на продукт: line weight, corner, filled vs outline.  
2. Grid: 24 / 32 / 48 design; рисуй на pixel grid.  
3. Optical balance: сложные глифы чуть крупнее простых в том же боксе.  
4. Meaning: универсальные (gear, lock, close) ок; уникальные механики — label рядом.  
5. Цвет иконки не единственный носитель статуса.

### Состояния

`active / inactive / disabled` — opacity или отдельный glyph, не «другая метафора».

### Rarity frames

Рамка/шейп rarity ≠ только hue. Добавь pattern / corner cut / star count.

Маркетинг может быть громче.  
In-game UI сохраняет читаемость и tokens. Не тащи clickbait-композицию в HUD.
